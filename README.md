# simple aimade night checkin program

#### 介绍
个人利用ai制作的，低成本实现愚蠢元大元自动晚签的方式。

前情提要：
本仓库的教程操作较为简单，可以把这个当作学习的机会，况且真的会有收获🤓
而且我只是一个讨厌晚签，只会用ai的笨蛋，不提供任何技术指导和后续项目更新

不解释同学！！！不解释！！！

#### 实现需求及效果：

1.一台可以在晚上8点后联网的电脑
2.你的手机
3.一个注册server酱的账号（自己查是什么）

效果：每天的签到操作自动发到你的手机上
